# 🦅 Travel Eagle

**Travel Eagle** is a React-based visa application and travel services website that provides users with access to multiple offerings including E-Visas, Umrah packages, flights, hotels, and tour packages — all in a clean and modern user interface.

---

## 🌟 Key Features

- **E-Visa Application** for countries like Saudi Arabia, UAE, UK, Canada, etc.
- **Umrah Service** packages including visa, hotel, and travel.
- **Flight Booking** for domestic and international travel.
- **Hotel Reservations** with flexible options.
- **Tour Packages** with curated experiences.
- **Login/Sign-up Form** for user access and tracking.
- **Responsive UI** built with Tailwind CSS.
- **Tab Navigation Interface** for seamless user experience.

---

## 🛠️ Built With

- **React JS** – Component-based frontend library
- **Tailwind CSS** – Utility-first CSS framework
- **ShadCN UI** – Reusable UI components (Card, Tabs, Input, etc.)
